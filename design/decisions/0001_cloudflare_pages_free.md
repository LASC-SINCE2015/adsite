# 0001 Cloudflare Pages の無料プランで公開し、GitHub 連携で自動公開する

- 状態: 採用
- 日付: 2026-11-05

## 状況

運用費は完全無料（月額 0 円）で、アクセスが急に増えても請求が発生しないことが条件。アフィリエイト広告を載せるため、商用利用が規約上認められている必要がある。

## 決定

- Cloudflare Pages の無料プランで、`site/` フォルダをそのまま配信する。
- GitHub リポジトリと Cloudflare Pages を連携させ、push で自動公開する。
  - 本番ブランチ: `master`（`<プロジェクト名>.pages.dev`）
  - それ以外のブランチ（`develop`・機能ブランチ）: Cloudflare Pages のプレビュー URL（`<ブランチ名>.<プロジェクト名>.pages.dev`）
- ドメインは当面 `pages.dev` を使い、独自ドメインは収益化・知名度が上がってから検討する。

## 理由

- 帯域幅が無制限で、クレジットカード不要。上限超過による請求が起きない。
- GitHub 連携だけで本番とプレビューが分かれるので、テスト環境を別に用意しなくてよい。
- GitHub Actions やデプロイ用の鍵が不要で、管理するものが少ない。

## 影響

- Cloudflare Pages の設定（ビルドコマンド: なし、出力ディレクトリ: `site`）は Cloudflare のダッシュボードで行う。
