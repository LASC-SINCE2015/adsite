# 0002 初期はビルドなしの静的 HTML / CSS / JS で作る

- 状態: 採用
- 日付: 2026-11-05

## 状況

Phase 1 はトップページ（プロフィール・作品カード一覧）と静的ページ数枚だけで、動的な処理はない。仕様では HTML / CSS / JS か React などを使うとしている。

## 決定

- ビルドツール（npm・フレームワーク）を使わず、`site/` に置いた HTML / CSS / JS をそのまま公開する。
- 作品の一覧は `site/data/works.json` にまとめ、JS で読み込んでカードを作る。作品の追加はこの JSON を直すだけで済むようにする。

## 理由

- インストールするものがなく、PC を重くしない。Cloudflare Pages 側のビルドも不要で、壊れる箇所が少ない。
- ページ数が少ないうちは、フレームワークの利点（部品の使い回し・状態管理）が小さい。

## 影響

- ヘッダー・フッターなどの共通部分は各 HTML に書くか、JS で差し込む。
- ページが増えて共通部分の管理がつらくなったら、静的サイトジェネレーター（Astro など）への移行を新しい ADR で検討する。
- Phase 2（Supabase の感想コメントなど）は、ブラウザから Supabase の JS ライブラリを使う形で追加できる。
