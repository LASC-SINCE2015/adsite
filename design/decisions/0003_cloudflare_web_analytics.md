# 0003 アクセス解析は Cloudflare Web Analytics を使い、Pages のダッシュボードで有効にする

- 状態: 採用
- 日付: 2026-11-07

## 状況

どの作品・ページが見られているか、どこから来ているかを知りたい。条件は、完全無料であること、閲覧者の情報をなるべく扱わないこと（Cookie の同意バナーを出さずに済むこと）。

## 決定

- アクセス解析には Cloudflare Web Analytics を使う。
- 計測用のスクリプトはソースに書かず、Cloudflare Pages のダッシュボード（プロジェクト → Metrics → Web Analytics）で有効にして、配信時に自動で挿入させる。
- 来場者数カウンターのように、数字をサイト上に表示する機能は作らない。

## 理由

- 無料で、サイトをすでに Cloudflare Pages で配信しているため、追加の登録やタグの管理がいらない。
- Cookie やブラウザのストレージを使わず、閲覧者を追跡しないので、プライバシーポリシーの記載が簡単で、同意バナーもいらない。
- Google Analytics 4 も無料だが Cookie を使う。このサイトの規模では、Cloudflare Web Analytics で見られる内容（ページビュー・訪問数・ページ・参照元・国・端末）で足りる。
- 来場者数カウンターは見せ方として古く、数字が小さいうちは逆効果になりやすい。サイト上に数字を出すなら、作品ごとの人気表示などを別途検討する。

## 影響

- 有効・無効の切り替えはダッシュボードで行うため、リポジトリの HTML には計測用のタグが出てこない。
- 解析の結果は Cloudflare のダッシュボードで確認する。
- 解析ツールを変えるときは、`site/privacy.html` の「アクセス解析」も直す。
