# 設計書 (design)

adsite の設計書（どう作るか）を置くフォルダです。仕様（何を作るか）は [spec/](../spec/README.md) を参照してください。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| [architecture/](architecture/README.md) | フォルダ構成・作品データの持ち方 |
| [decisions/](decisions/README.md) | 設計判断の記録（ADR） |

## 実装状況の書き方

- 設計書は、現在の実装（site/）に合わせて書く。
- 仕様にはあるが作っていないものは「**未実装**」と明記する。

※ アフィリエイトの ID など、アカウントに関わる実値はリポジトリでは管理しません。
