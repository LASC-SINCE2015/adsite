# 設計書 (design)

adsite の設計書（どう作るか）を置くフォルダです。仕様（何を作るか）は [spec/](../spec/README.md) を参照してください。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| [architecture/](architecture/README.md) | フォルダ構成・作品データの持ち方・動きのある仕掛け |
| [decisions/](decisions/README.md) | 設計判断の記録（ADR） |

## 実装状況の書き方

- 設計書は、現在の実装（site/）に合わせて書く。
- 仕様にはあるが作っていないものは「**未実装**」と明記する。

## サイトについて・プライバシーポリシーの更新

次のものを追加・変更したときは、`site/about.html` と `site/privacy.html` の記載も合わせて直し、制定日の下に改定日を書く。

- アクセス解析ツール（今は「使用していない」と書いている）
- 広告・アフィリエイトのサービス
- お問い合わせの方法
- 閲覧者の情報を受け取る機能（Phase 2 の感想コメントなど）

広告を置く箇所には「PR」または「広告」と表示する（about.html にそう書いているため）。

※ アフィリエイトの ID など、アカウントに関わる実値はリポジトリでは管理しません。
