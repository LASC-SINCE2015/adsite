# 動きのある仕掛け (interactions)

サイトに入れている、触って反応する仕掛けの設計です。どれも外部のライブラリやサービスを使わず、ブラウザの機能だけで動かします。閲覧者の情報を保存・送信するものはありません（Cookie・ローカルストレージも使わない）。

## 共通の方針

- **「視差効果を減らす」設定（`prefers-reduced-motion: reduce`）のときは動かさない。** 内容はそのまま見られるようにする。
- **使えない機能があっても、ページの内容は普通に表示する。** 仕掛けは「上乗せ」で、なくても困らない作りにする。
- **表示速度を落とさない。** 動くものがあるときだけ描き、止まったら描くのをやめる。画面の外やタブが裏にあるときも止める。
- 演出が作品の紹介より目立ちすぎないようにする。

## 見出しの粒子演出（assets/js/hero-particles.js）

トップページの見出し「つくったものを、並べる場所。」を細かい粒子で描きます。

- 読み込み時は、ばらばらの粒子が集まって文字になる。
- カーソルを近づけると周りの粒子が押しのけられて文字がほどけ、離すと元に戻る。クリック・タップでは、その周りの粒子が弾け飛ぶ。

作り方:

1. 見出しの文字を 1 文字ずつ、画面上と同じ位置・同じフォントで裏の canvas に書く（位置は `Range.getClientRects()` で 1 文字ずつ測るので、画面幅による折り返しにも追従する）。
2. 裏の canvas の画素を一定の間隔で調べ、文字がある点を粒子の「元の位置」にする。
3. 粒子は、元の位置へ戻るばね・速度の減衰・カーソルからの反発の 3 つの力で動かす。
4. 本物の見出しの文字は消さずに透明にする（検索エンジン・読み上げソフト・印刷のため）。
- 画面の大きさが変わったら作り直す。ダークモードの切り替えで色を読み直す。
- `data-particle-title` を付けた要素が対象。

## 作品カードの 3D チルト（assets/js/card-tilt.js）

作品カードの上でカーソルを動かすと、カードがカーソルの方向へ少し傾き（最大 6 度）、カーソルの位置に光が当たったように明るくなります。

- 傾きと光の位置は CSS 変数（`--tilt-x`・`--tilt-y`・`--shine-x`・`--shine-y`）で渡し、見た目は CSS で作る。
- マウスなど細かく指せる入力（`hover: hover` かつ `pointer: fine`）のときだけ動かす。タッチ操作では動かさない。
- 計算は 1 フレームに 1 回にまとめる。

## タグで絞り込み・並び替えアニメーション（assets/js/main.js）

作品一覧の上に、使われているタグのボタンを並べます（作品数が多い順）。押すとそのタグの作品だけを表示します。カードの中のタグを押しても同じように絞り込めます。もう一度押すか「すべて」で解除します。

- 絞り込んだ状態は URL の `?tag=` に入れる（再読み込み・共有してもそのまま）。
- View Transitions API（`document.startViewTransition`）が使えるブラウザでは、残ったカードが新しい位置へ動き、消えるカード・現れるカードは縮みながら消え、広がりながら現れる。使えないブラウザでは、アニメーションなしで切り替わる。
- 絞り込み後の件数は、読み上げソフトにも伝わるように `aria-live` で表示する。

## 404 ページのミニゲーム（404.html・assets/js/game-404.js）

存在しない URL を開いたときのページに、ブロックくずしを置いています。ブロックは「404」の形に並んでいて、全部くずすとクリアです。

- 操作: マウス・指でバーを動かし、クリック・タップで発射。キーボードは ← → で移動、スペース（または Enter）で発射・一時停止。
- のこり 3 回。ブロックをくずすたびにボールが少し速くなる。ベストスコアは、ページを開いている間だけ覚える（保存はしない）。
- 速いボールがブロックをすり抜けないよう、1 フレームの移動を細かく分けて当たりを判定する。
- ゲームは自動では始めない。ページの上部に「トップページへ戻る」ボタンを置き、遊ばない人がすぐ戻れるようにする。
- 検索結果に出ないよう `noindex` を付ける。
