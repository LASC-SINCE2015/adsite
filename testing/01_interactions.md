# 確認内容: 動きのある仕掛け

[動きのある仕掛け](../design/architecture/interactions.md)の確認項目です。PC（マウス）とスマートフォン（タッチ）の両方で確認します。

## 見出しの粒子演出

- [ ] トップページを開くと、粒子が集まって見出しの文字になる
- [ ] 止まったときの文字が、ずれやにじみなく読める
- [ ] カーソルを近づけると文字がほどけ、離すと元に戻る
- [ ] クリック・タップした周りの粒子が弾ける
- [ ] 画面幅を変えても（折り返しが変わっても）、文字の形が正しい
- [ ] ダークモードに切り替えると、文字の色が変わる
- [ ] 「視差効果を減らす」設定では、普通の文字のまま表示される
- [ ] 見出しの文字を選択・コピーできる。印刷すると普通の文字で出る

## 作品カードの 3D チルト

- [ ] マウスを動かすと、カードがカーソルの方向へ傾き、光が当たる
- [ ] カードから離れると、なめらかに元に戻る
- [ ] タッチ操作では傾かない
- [ ] 「視差効果を減らす」設定では傾かない

## タグで絞り込み・並び替えアニメーション

- [ ] タグのボタンを押すと、そのタグの作品だけになり、件数が変わる
- [ ] カードの中のタグを押しても絞り込める。もう一度押すと解除される
- [ ] 「すべて」で解除される
- [ ] 絞り込むと URL に `?tag=` が付き、再読み込みしても同じ状態になる
- [ ] 存在しないタグの `?tag=` を付けて開くと、すべての作品が表示される
- [ ] 対応ブラウザ（Chrome・Edge など）で、カードが動くアニメーションになる
- [ ] 非対応ブラウザでも、アニメーションなしで絞り込める
- [ ] キーボード（Tab・Enter）でも操作できる

## 404 ページのミニゲーム

- [ ] 存在しない URL（例: `/abc`、`/abc/def`）を開くと、404 ページが表示される（デザインが崩れない）
- [ ] 「トップページへ戻る」とヘッダー・フッターのリンクが正しく動く
- [ ] クリック・タップで始まり、バーを動かしてボールを打ち返せる
- [ ] キーボード（← → とスペース）で遊べ、遊んでいる間は画面がスクロールしない
- [ ] ブロックを全部くずすとクリア、3 回落とすとゲームオーバーになる
- [ ] 別のタブを見ると一時停止する
- [ ] スマートフォンで、指でバーを動かせる
- [ ] ダークモードで見やすい色になる
