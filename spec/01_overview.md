# 概要・基本方針・インフラ・機能要件

ポータル＆アフィリエイトサイトの仕様書（完全無料・リンク集約型）。

## 1. プロジェクト基本方針

| 項目 | 内容 |
|---|---|
| サイトの役割 | 自作の Web アプリや Web アプリゲームを紹介・誘導するポータルサイト（ポートフォリオ兼まとめサイト）。 |
| アプリ・ゲームの実体 | 各作品のシステムは個別に稼働させ、紹介サイトからはリンクで外部（または別環境）に飛ばす構成とする（紹介サイト本体の負荷やシステムの複雑化を避けるため）。 |
| ジャンル・技術 | 定めず、今後作るあらゆるアプリ・ゲームの情報を柔軟に掲載・追加していく。 |
| 運用コスト | 完全無料（月額 0 円）。勝手な有料プランへの切り替えや予期せぬ請求が絶対に発生しない設計にする。 |
| 収益化 | アフィリエイト広告やディスプレイ広告の掲載を許可されたプラットフォームを使用する。 |
| ドメイン | 初期は Cloudflare Pages が提供する無料の `pages.dev` サブドメインを使用する。将来的に収益化や知名度向上を果たした段階で、独自ドメインへの移行を検討する。 |

## 2. インフラ・技術仕様（0 円完全保証）

| 役割 | 採用サービス | 無料枠・仕様 | アクセス急増時の挙動（安全性） |
|---|---|---|---|
| ホスティング & 配信 | Cloudflare Pages | 帯域幅（転送量）完全無制限。商用利用・アフィリエイトも規約上 OK。 | クレジットカード不要。無料の範囲内で安定稼働し、超過による突然の請求リスクなし。 |
| ソースコード管理 | GitHub | 無料のパブリック / プライベートリポジトリ。 | 完全無料。 |
| 将来の双方向機能（掲示板など） | Supabase（Free Tier）※将来追加時 | DB 容量 500MB / 月 5 万 MAU。 | クレジットカード未登録なら、上限を超えた場合は一時停止するだけで勝手に課金されない。 |

## 3. 機能要件

### Phase 1: ポータルサイト構築（初期リリース）

#### トップページ（ホーム / 一覧）

- 開発者プロフィール（技術アピール）
- 自作 Web アプリ・ゲームをカード形式で一覧表示する
  - サムネイル画像、タイトル、概要、タグ
  - 「アプリで遊ぶ / 使ってみる」ボタン（外部のアプリ本体 URL へリンク）

#### アフィリエイト・広告エリア

- サイト内のサイドバーや記事下、または紹介カードの関連枠に、A8.net やもしもアフィリエイトなどのリンクを配置する。

#### 静的ページ

- プライバシーポリシー
- サイトについて（アフィリエイト広告の掲載に関する表記など）

### Phase 2: 双方向機能の追加（将来拡張）

#### 閲覧者とのコミュニケーション機能

- Supabase などの無料 BaaS を後から組み込み、作品ごとの感想コメントや簡易掲示板を設置する。

---

## 4. デプロイ・公開の流れ

1. **開発**: ローカル環境で HTML / CSS / JS、または React などを用いてポータルサイトのコードを作成する。
2. **管理**: GitHub にリポジトリを作成し、コードをプッシュする。
3. **公開**: Cloudflare Pages と GitHub を連携させ、`git push` するだけで自動ビルド＆ `xxx.pages.dev` で無料公開する。
